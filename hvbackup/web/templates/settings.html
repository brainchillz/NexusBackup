API tokens

Tokens act with the owner's role. Send them as Authorization: Bearer hvb_…; the CLI reads HVB_TOKEN.

Verification

Reads the chunks of every restore point on a schedule and checks each against its hash, so damage on the repository disk shows up before a restore needs the data. Damaged points are flagged in the restore point lists and in the dashboard plug-in.

Notifications

A JSON document per ticked event to the URL. The test uses the fields as typed, saved or not.

Certificate

The HTTPS certificate of this server. A new one is served after a restart; the list below says what pins the current one and offers the re-push.
